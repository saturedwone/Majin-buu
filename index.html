⚠️ Limitaciones: Esta herramienta realiza desofuscación estática básica:
  • Decodifica strings en formato decimal (\110\121\073), hexadecimal (\x48\x65) y base64 (solo si detecta patrones simples).
  • Elimina expresiones matemáticas constantes (ej. 15000-14999 → 1).
  • Intenta eliminar código basura: variables no usadas, operaciones inútiles (solo casos evidentes).
  • No desofusca máquinas virtuales personalizadas (VM) ni ofuscadores avanzados como IronBrew, MoonSec v2+ con VM. Para esos necesitas análisis manual por capas.
Si el script contiene una VM (bucle while ... do con casos), el resultado no será ejecutable directamente.
Herramienta educativa · No garantiza desofuscación completa en scripts muy protegidos.
